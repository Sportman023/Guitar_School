# 🎸 Гитарная школа

Домашний тренажёр по музыкальной грамоте. Приложение задумано так, чтобы
дописывать в него новые темы по мере того, как их проходят в школе.

**Открыть:** https://sportman023.github.io/Gitar_School/

Работает прямо в браузере, без сервера и без интернета после первого запуска.
На одном устройстве могут заниматься несколько детей — у каждого свои звёзды
и своя гитара.

Первый блок: **ноты и цвета радуги**.

| Нота | Цвет | Лат. | На стане |
|------|------|------|----------|
| До   | Красный    | C | добавочная линейка снизу |
| Ре   | Оранжевый  | D | под первой линейкой |
| Ми   | Жёлтый     | E | первая линейка |
| Фа   | Зелёный    | F | между 1-й и 2-й |
| Соль | Голубой    | G | вторая линейка |
| Ля   | Синий      | A | между 2-й и 3-й |
| Си   | Фиолетовый | B | третья линейка |

## Запуск на компьютере

Приложение — это просто файлы в `public/`. Для локальной разработки есть
мини-сервер, нужен только Node.js 18+, зависимостей нет.

```bash
npm start          # затем открыть http://localhost:3000
npm run dev        # то же самое, но с авто-перезапуском при правках
PORT=8080 npm start
```

Публикация на GitHub Pages происходит сама: после `git push` в ветку `main`
GitHub Actions выкладывает папку `public/` (см. `.github/workflows/pages.yml`).

## Бета-версия

Чтобы учитель могла проверить изменения до того, как их получат дети, ветка
`beta` публикуется в подпапку того же сайта:
**https://sportman023.github.io/Gitar_School/beta/**

```bash
git checkout beta && git push                           # новая версия появится в /beta/ через минуту
git checkout main && git merge --no-ff beta && git push # учитель одобрила — выпускаем
git checkout beta && git merge --no-ff main && git push # после срочной правки прямо в main
```

Слияния — только с `--no-ff`. GitHub Pages выкладывает каждый коммит один раз:
если перемотать `main` на коммит, который уже выкладывался из `beta`, деплой
тихо пропустится и дети не получат новую версию. Поэтому workflow падает с
ошибкой, когда `main` и `beta` указывают на один и тот же коммит.

В бете внизу экрана плашка «БЕТА», свои игроки и звёзды и свой кэш для работы
без интернета: проверка беты на планшете ребёнка не трогает его прогресс.
Какая копия запущена, приложение понимает по адресу (`js/core/env.js`), поэтому
код в обеих ветках одинаковый и при выпуске ничего править не нужно.

## Что внутри

**Меню.** Главный экран — это гитара игрока, радужная полоска (нажми на цвет —
зазвучит нота) и плитки тем. Темы открываются по одной, внутри темы лежат её
разделы, так что главный экран остаётся коротким, сколько бы тем ни добавилось.
Тема, в которой появился раздел, которого ребёнок ещё не видел, помечается
значком «Новое!» — и сам этот раздел внутри темы тоже (до следующего захода).
Так заметно и новую тему, и новый раздел в старой. На карточке
раздела видно, как он идёт: три звёздочки за игру (одна — играли, две — 70%
правильных, три — все ответы верные) или пометка «Учим» у разделов-подсказок,
где игры нет.

**Игроки.** При каждом запуске приложение спрашивает «Кто сегодня играет?».
У игрока есть имя и зверёк; звёзды, результаты, настройки и гитара у каждого
свои. Сменить игрока — кнопка со зверьком в шапке, изменить, сбросить прогресс
или удалить — карандаш на карточке игрока (взрослые кнопки собраны там, чтобы
ребёнок не обнулил звёзды случайно). Всё хранится в браузере (`localStorage`)
и никуда не отправляется; если очистить данные браузера, прогресс пропадёт.

**Моя гитара.** Звёзды за игры не тратятся, а открывают детали для гитары:
формы корпуса, цвета, наклейки (до трёх сразу) и эффекты. Ребёнок сам собирает
гитару в мастерской. На главном экране видно текущую гитару и сколько звёзд
осталось до следующей детали, а когда что-то открывается — появляется подарок.
У каждой формы свой звук (нейлон, укулеле, электрогитара, космическое эхо,
тяжёлый рок) и по три мелодии: народные и классические или написанные для
приложения рифы (`public/js/data/tunes.js`).

| Звёзд | Что открывается |
|------:|-----------------|
| 0     | классическая форма, цвета «Дерево» и «Красный», наклейка «Звёздочка» |
| 10–50 | наклейки «Сердечко», «Нотка», цвета «Оранжевый», «Жёлтый» |
| 70–250 | форма «Сердечко», цвета «Зелёный», «Голубой», «Синий», наклейки «Молния», «Цветок», эффект «Блёстки», форма «Электрогитара» |
| 290–650 | цвета «Фиолетовый», «Розовый», «Радуга», наклейки «Смайлик», «Радуга», эффект «Сияние», форма «Звезда» |
| 750–1500 | наклейка «Корона», форма «Стрела», цвета «Золото» и «Космос», эффект «Огонь» |

Точные пороги и названия — в `public/js/data/guitar.js`.

**Ноты и цвета**

* **Учим ноты** — карточки с названием и цветом ноты; нажатие проигрывает её на фортепиано.
* **Нота → Цвет** — показываем ноту, ребёнок выбирает цвет.
* **Цвет → Нота** — наоборот.
* **Собери радугу** — расставить ноты по порядку от До до Си.
* **Угадай на слух** — на фортепиано звучит опорная До, потом загаданная нота.
  Все ноты из первой октавы (До–Си), так что загадка всегда не ниже опорной До.

**Пальцы**

* **Пальцы 1–4 и pima** — рисунок руки с подписанными пальцами и карточки:
  левая рука считает пальцы цифрами 1–4 (большой без номера, он держит шейку),
  правая называет их буквами p, i, m, a — от испанских pulgar, índice, medio,
  anular. Раздел-подсказка, без игры и звёзд.
* **Какой это палец?** — на рисунке руки подсвечен палец, ребёнок выбирает его
  обозначение: цифру или букву.
* **Покажи палец** — дана цифра или буква, ребёнок нажимает нужный палец на
  рисунке. На картинке не сказано, какой руке принадлежит обозначение: цифра —
  значит левая, буква — правая. Большой палец левой руки и мизинец правой тоже
  можно нажать, но они всегда неверный ответ.

В обеих играх над вопросом можно выбрать руки: левую, правую или обе. Когда
выбраны обе, среди ответов всегда есть тот же палец другой руки (рядом с 1
стоит i), чтобы нельзя было угадать, не помня, что левая — цифры, а правая —
буквы.

**Нотный стан**

Сначала разделы-подсказки по каждой октаве, потом общие игры, в которых
можно выбрать, какие октавы тренировать.

* **Первая октава** — что такое нотный стан и скрипичный ключ, лесенка из семи нот
  (любую можно послушать) и карточки: где живёт каждая нота первой октавы.
* **Вторая октава** — лесенка из семи нот До–Си (любую можно послушать) и карточки:
  где живёт каждая нота второй октавы.
* **Малая октава** — то же самое для пяти нот Ми–Си, которые живут ниже стана,
  на добавочных линеечках.
* **Лесенка октав** — все октавы подряд на одном длинном стане, со скобками
  под каждой октавой; каждую нотку можно послушать.
* **Читаем ноты** — показываем ноту на стане, ребёнок называет её.
* **Ставим ноты** — наоборот: дано название с октавой, надо выбрать правильный стан.

Над вопросом в играх — переключатели октав («малая», «1-я», «2-я»): выбор общий для обеих
игр и запоминается у игрока, хотя бы одна октава всегда включена, смена выбора
начинает раунд заново. Если включена одна октава, ответ — просто имя ноты. Если
несколько, ответ — имя и октава («До / 2 октавы»), и среди вариантов всегда есть
такая же нота из другой октавы: цвет у них одинаковый, так что октаву приходится
читать по стану.

Переключатель **«цветные нотки»** закрашивает головки нот цветами радуги — опора на
уже выученное. Когда станет легко, его выключают, и ноты становятся чёрными, как в
настоящей нотной тетради. В обратном задании («Ставим ноты») ноты всегда чёрные:
иначе цвет подсказывал бы ответ, и стан можно было бы не читать.

### Ноты первой октавы на стане

| Нота | Где стоит | Штиль |
|------|-----------|-------|
| До   | на первой добавочной линеечке под станом | вверх |
| Ре   | под первой линейкой | вверх |
| Ми   | на первой линейке | вверх |
| Фа   | между 1-й и 2-й линейками | вверх |
| Соль | на второй линейке (вокруг неё завиток ключа) | вверх |
| Ля   | между 2-й и 3-й линейками | вверх |
| Си   | на третьей линейке | вниз |

### Ноты второй октавы

Октавы перечислены в `OCTAVES` в `public/js/data/notes.js`: новая октава —
это ещё одна запись там, лесенка октав и переключатели в играх подхватят её сами.

| Нота | Где стоит на стане |
|------|--------------------|
| До   | между 3-й и 4-й линейками |
| Ре   | на четвёртой линейке      |
| Ми   | между 4-й и 5-й линейками |
| Фа   | на пятой линейке          |
| Соль | над пятой линейкой        |
| Ля   | на добавочной линеечке над станом |
| Си   | над добавочной линеечкой  |

Штиль у всех нот второй октавы направлен вниз. Цвета те же, что и у первой
октавы: цвет — это имя ноты, а не её высота.

### Ноты малой октавы

Пока только Ми–Си: ниже них в школе ещё не спускались.

| Нота | Где стоит на стане |
|------|--------------------|
| Ми   | под третьей добавочной линеечкой |
| Фа   | на третьей добавочной линеечке   |
| Соль | под второй добавочной линеечкой  |
| Ля   | на второй добавочной линеечке    |
| Си   | под первой добавочной линеечкой  |

Добавочные линеечки под станом считают сверху вниз: на первой сидит До первой
октавы, на второй — Ля малой, на третьей — Фа малой. Штиль у нот малой октавы
направлен вверх и дотягивается до средней линейки стана — так в настоящих нотах
низкую ноту привязывают к стану.

Из-за нот за пределами пяти линеек картинка стана растёт вниз (малая октава) и
вверх (Ля и Си второй): размер считается сразу для всего набора нот
(`staffBox` в `public/js/core/staff.js`), чтобы соседние карточки и вопросы
в игре были одинаковыми и стан не прыгал от вопроса к вопросу. Лесенку нот
картинка никогда не сжимает меньше собственного размера — если ряд не влезает
в экран, он прокручивается вбок.

## Звук

Все ноты во всех разделах звучат одинаково — на настоящем рояле: записи
[Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3)
(Yamaha C5), автор — Alexander Holm, лицензия
[CC BY 3.0](http://creativecommons.org/licenses/by/3.0/). Рояль записан через
малую терцию, поэтому в `public/audio/piano/` лежат только двенадцать клавиш
(Ре♯, Фа♯, Ля малой октавы, До, Ре♯, Фа♯, Ля первой, До, Ре♯, Фа♯, Ля второй
и До третьей), остальные ноты получаются из ближайшей записи сдвигом на полутон. Громкость записей выравнивается, чтобы она
не подсказывала ответ.

Синтезируются в браузере только сигналы «верно / неверно» и перебор струн
в мастерской: там звучит гитара самого ребёнка, а не нота, которую учат.

## Как добавить новую тему

1. Создать файл в `public/js/modules/`, экспортировать объект:

```js
export default {
  id: 'ritm',
  title: 'Длительности',
  subtitle: 'Целая, половинная, четверть',
  emoji: '🥁',
  accent: '#26A69A',
  group: 'ritm',        // id темы из GROUPS
  kind: 'learn',        // только для разделов без игры
  mount(root) {
    // draw the section inside root
    // optionally return a cleanup function
  },
};
```

2. Добавить его в список `MODULES` в `public/js/modules/index.js`.
   Поле `group` — это id темы из списка `GROUPS` в том же файле: под этой
   плиткой раздел появится в меню. Если темы ещё нет, дописать её в `GROUPS`
   (`id`, `title`, `subtitle`, `emoji`, `accent`) — новые темы идут в конец
   списка, чтобы то, что учат сейчас, было последней плиткой.
   Раздел без игры, который просто объясняет, помечается `kind: 'learn'` —
   тогда вместо результата на карточке будет пометка «Учим».

Для викторин с вариантами ответа есть готовый движок `createQuiz()`
из `public/js/core/quiz.js` — нужно описать только вид вопроса и ответов.
Набор нот задаётся полем `notes` (по умолчанию первая октава; можно передать
функцию — она вызывается в начале каждого раунда), неправильные варианты —
`pickOthers`, текст при ошибке — `explainAnswer`. Элементы управления над
вопросом рисует `renderControls({ redraw, restart })`: `redraw` перерисовывает
тот же вопрос, `restart` начинает новый раунд.
